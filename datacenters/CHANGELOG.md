# Changelog

## 2026-10-09 — first public release

- Curated records for large data center builds worldwide, each statement linked to its source.
- Record contract (schema version 1.0) with separate power bases and scopes, partial dates,
  explicit location precision, and paraphrase-only text.
- Uncurated OpenStreetMap (ODbL) and Wikidata (CC0) layers with retrieval manifests.
- Downloads in CSV, JSON, JSON Lines, GeoJSON, SQLite, Excel and Parquet; Frictionless Data Package;
  static JSON API; Atom feed.
- Interactive explorer with a dependency-free map, filters with shareable URLs, and filtered CSV
  export; a static page per project.
